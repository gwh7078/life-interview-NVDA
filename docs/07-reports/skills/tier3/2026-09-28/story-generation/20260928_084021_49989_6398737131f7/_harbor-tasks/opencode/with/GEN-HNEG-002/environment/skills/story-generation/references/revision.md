# 成稿修改规则

仅在 `mode = revision` 时读取。`SKILL.md` 中“修改模式”的结构约束优先。

1. 先以 `selected_document` 确认现有顺序、重点和章节结构；不要从 Story Summary 另建骨架。
2. 按当前主人公 Transcript 校正旧稿：应用明确纠正，补入有证据的新信息，删除或改写无证据及相矛盾的细节；未解决的矛盾继续保持不确定。
3. 其余以局部编辑为主，润色措辞、段落衔接和节奏。默认保留叙事顺序、整体结构和文章重点。
4. 只有用户明确要求时才重构，并且只调整其要求的范围。无论结构如何变化，都不得突破事实边界。
5. 交付前确认没有以 Story Summary 建立第二套叙事，也没有因润色保留无法由当前证据支持的细节。
