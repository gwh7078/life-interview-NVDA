# 人生采访局 · 手机端线框演示

这是用于讨论产品结构和交互闭环的静态前端原型，不连接真实麦克风、AI 或后端数据。

打开 `index.html` 后，可以从页面右上角跳转到任意关键页面，也可以在手机框内走完整路径：

`首次通话 + 核心清单 → 人生首页时间流 → 阶段/故事详情 → 连续语音通话 → 只读访谈结果 → 故事整理与定稿`

演示数据来自最新的回忆录补充材料，写在 `app.js` 中；样式和页面结构分别在 `styles.css`、`index.html` 中。通话界面提供自动更新的清单、暂停和挂断；访谈结果只展示生成内容并以“完成”结束，修改回到对应详情页或继续通话。完整故事可以进入独立整理页，用语音提出改稿意见并定稿。本演示不连接真实麦克风、AI 或后端数据。
