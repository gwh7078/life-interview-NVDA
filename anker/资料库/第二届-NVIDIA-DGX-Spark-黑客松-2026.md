# 第二届 NVIDIA DGX Spark 黑客松（2026）

## 1. 活动概况

第二届主题为 **“让 Agent 创作一切”**，重点是多模态 Agent 和本地智能体应用。公开报道显示，活动由 NVIDIA Developer Community、StepFun、XSUPERZONE 等组织/合作方共同推进，面向 AI 开发者、AI 工程师、学生、多媒体创作者和企业团队。

## 2. 时间线与组织方式

| 阶段 | 时间 | 公开信息 |
|---|---|---|
| 报名 | 2026-06-24—2026-07-11 | 2—5 人组队；每人只能参加一队 |
| 训练营 | 2026-07-12 | 规则、评分和技术实战 |
| 初赛与提交 | 2026-07-12—2026-07-22 | 完成项目并提交 |
| 评审 | 2026-07-23—2026-07-26 | 初赛评审 |
| 决赛路演 | 2026-08-02 | 上海现场路演 |

公开资料显示名额约 100 个。报名后期曾出现远程 DGX Spark 资源已满、但自有 DGX Spark/GB10 团队仍可参与的提示，这说明硬件资源和算力申请要尽早确认。

## 3. 训练营与技术方向

公开介绍提到的实战方向包括：

- 规则、评审标准和作品提交；
- DGX Spark + Step 3.7 本地 Agent Team；
- 本地视觉生成 Agent；
- 桌面机器人 Agent。

它反映出上一届的核心不是“换一个模型做聊天”，而是把多模态输入、任务规划、工具调用和可观察执行串成闭环。

## 4. 决赛与公开报道

合作方复盘报道称，10 支队伍晋级决赛；另一篇上海活动报道提到决赛现场有 13 支队伍展示项目。公开口径存在差异，不能把两者直接等同为同一个统计口径。

报道覆盖的项目方向包括推理优化、具身智能、AIGC 生产、教育、文化娱乐、金融和智能硬件等。

## 5. 公开项目复盘与可借鉴点

### 5.1 WatcheRobot / SparkHT

公开仓库：<https://github.com/orulink-ai/SparkHT-Focus-Demo>

项目把视觉观察、Agent 编排、本地模型服务和机器人控制连起来。可借鉴：

- 观察结果先结构化，再交给 Agent 判断；
- 将 DGX Spark 本地模型、语音、视觉和控制服务拆开；
- README 明确区分实际测得能力与理论能力；
- 用完整闭环展示本地推理的价值。

### 5.2 Superhero / DreamBook

公开仓库：<https://github.com/Clover-ASH/DGX_Spark2_hackathon>

项目使用本地 LLM 与本地图像生成模型完成角色和故事创作。可借鉴：

- 用技术报告说明模型、硬件、流程和性能；
- 把文本、图像和故事编排成一个完整产品体验；
- 选择能在本地资源下稳定运行的模型组合。

### 5.3 Neow

公开仓库：<https://github.com/Ephemeral2077/Neow>

项目体现图像生成 Agent 的闭环思路。可借鉴：

- 将创作过程拆成可复用步骤；
- 为中间状态和失败情况留出检查点；
- 让用户可以修改目标，而不是一次性生成不可控结果。

### 5.4 GeekPie SparkLive Studio

公开复盘：<https://www.cnblogs.com/lsCoinred/articles/21801306/dgx-spark-hackthon>

可借鉴的工程经验：

- 不要重复实现成熟的 OBS、FFmpeg、Whisper 等底层能力；
- 把 Agent 编排层作为核心差异化；
- 用结构化事件连接多模态模块；
- 高风险动作采用“提案 → 策略检查 → 工具注册 → 审计”的流程；
- 清楚区分 mock 演示和真实能力。

## 6. 与第三届的差异

| 维度 | 第二届 | 第三届 |
|---|---|---|
| 主题 | 让 Agent 创作一切 | Agent Skills 开发挑战赛 |
| 重心 | 多模态创作、视觉 Agent、桌面机器人 | 领域技能封装、工具调用、标准工作流 |
| 参考重点 | 如何把多模态链路跑通 | 如何把专业方法变成可复用 Skill |
| 对“人生采访局”的启示 | 音频、文字、图片、多模态协作 | 采访方法、追问、事实确认、成稿技能化 |

## 7. 适合本项目的结论

不要复制上一届的“创作题材”，应复制其工程方法：本地模型组合、结构化中间结果、可观察 Agent 流程、真实能力与 mock 分离、现场失败可恢复。第三届更看重的是：这些方法能否被包装成稳定、可说明、可复用的 Agent Skills。
