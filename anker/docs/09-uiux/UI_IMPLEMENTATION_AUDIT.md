## 状态覆盖

所有页面继续保留并用统一视觉语言表达：

- Loading：页面或内容正在读取时给出明确的状态文字。
- Empty：没有阶段、故事、成稿或可成书内容时给出下一步入口。
- Processing：异步整理阶段展示当前工作步骤，可按产品定义离开页面。
- Error：显示可理解的错误原因和原有重试操作。
- Disabled：只在业务条件不满足时禁用，例如 Story 未达到 `complete` 时不能生成成稿。
- Success：展示真实完成结果和下一步入口。

## 固定产品约束

- `Life Stage → Story → Story Document → Book` 的数据层级不变。
- Story 状态只使用“资料较少 / 正在完善 / 已可成稿”。
- 不用虚构图片填充没有图片数据的 Story。
- 前端不直接改变后端业务、Realtime 协议、数据库边界或 Agent 工具边界。
