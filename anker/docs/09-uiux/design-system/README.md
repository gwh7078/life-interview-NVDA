# Design System

本目录用于沉淀「人生采访局」后续统一的 UI 设计系统。

当前视觉基线以 `../references/ui-reference-core-v1.webp` 为参考，产品功能与交互逻辑仍以当前 `main` 代码和 `docs/product/` 最新产品文档为准。

后续在此维护：

- Color Tokens
- Typography
- Spacing / Radius / Shadow
- Button / Form / Card / Status
- Dialog / Drawer / Bottom Sheet
- Interview Call UI
- Processing / Result
- Story / Timeline
- Document Reader
- Responsive / Mobile Safari 规则

## 约束

1. 参考图只决定视觉与层级，不新增产品中不存在的按钮或功能。
2. 产品已有功能即使参考图未展示，也必须保留并使用统一视觉语言补齐。
3. Interview 保持 Call UI，不转为聊天气泡 UI。
4. Story 状态固定为「资料较少 / 正在完善 / 已可成稿」，不引入百分比完成度。
5. 移动端优先，首先以约 390px 宽度设计与验收。
