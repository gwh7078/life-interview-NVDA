**郭先生**：回院后，我们水泥工艺专业的12名同事，在工艺环保室集中进行了为期半年的绘图学习。当时没有计算机辅助设计，所有图纸都靠图板、丁字尺手工绘制。在资深高工手把手指导下，我以鲁南水泥厂原料粉磨子项的非标设计为实战课题反复打磨。

**AI**：那半年最重要的收获是什么？

**郭先生**：绘图精度和设计逻辑提高得很快，逐渐建立起严谨的工艺设计思维。集中绘图结束后，我被分配到新技术室水泥工艺组，正式开始新技术研发和工程设计。

**AI**：你第一次独立承担的设计子项是什么？

**郭先生**：是河北省石家庄市水泥厂的生料均化库。真正独立承担一个子项，还是有不小的压力。老专家和同事从怎么入手、怎么绘图，到设计的指导思想和方法，一点点掰开揉碎地教我。

**AI**：那时画图的日常是什么样？

**郭先生**：夏天天热，一出汗手上的汗就滴到图纸上；贴在图板上前倾着身子，腰也常常酸疼。但那时候年轻，没觉得有多苦。白天上班，晚上经常加班画图，生活基本上就是围着工作转。

**AI**：图纸第一次交上去就能通过吗？

**郭先生**：老专家审核得很严格，不合适的地方会退回来反复修改，直到满足设计要求才通过。石家庄那个项目就是这样一点点磨出来的。

**AI**：（不追问尚无证据的细节）下一次我们可以继续聊1993年到1999年的项目和驻厂调试。今天先把这段基本功训练保存下来，可以吗？

### 对话包 D：工程师阶段项目与边界提醒

**AI**：1993年晋升工程师以后到1999年晋升高级工程师之间，你印象比较清楚的项目有哪些？

**郭先生**：这七个项目，是晋升工程师之后到高级工程师之间的。牡丹江水泥技改、山西新绛水泥、上海海螺和奉贤这些，我担任项目负责人；伊朗粉磨站、苏州三水、大同矿业、苏州南新等，是参与设计、校对和审核。

**AI**：这段是否需要把每个项目的规模都完整写出来？

**郭先生**：当时做了好多项目，有些也不记得了。项目就用文字叙述，用“等”来代替，不用写得太细。

**AI**：那我暂时整理为：你主持完成牡丹江水泥技改、山西新绛水泥、上海海螺/奉贤粉磨站等项目，同时参与伊朗粉磨站、苏州三水、大同矿业水泥、苏州南新等项目的设计、校对和审核。驻厂调试另作为一个故事继续整理。这样可以吗？

**郭先生**：可以，工程师阶段驻厂调试时间比较长，调试单独建一个内容就可以了。

## 七、可继续放入 P07 的短对话素材

这些内容已有正常中文记录，但有的仍适合做 LifeStage 访谈中的动态发现，不必一次全部塞入 Story 卡片。

### 1. 小学：煤油灯和鸡粪

**AI**：小学放学以后，除了做作业，你们还会做什么？

**郭先生**：放学以后会和同学奔向田埂，帮家里除草、插秧、割柴。晚上在煤油灯底下做作业，光线很暗，有时候鼻子和鼻毛都被煤油灯的烟熏黑。

**AI**：那时有没有做过和上学有关的“小事”？

**郭先生**：捡鸡粪交到大官庄大队的苹果园里做肥料，有时能赚一点钱拿回家，家长非常高兴；还捡蝉蜕卖给学校，一两个月结算一次。

### 2. 高中：住校、订饭和过河

**AI**：莒县一中三年住校，平时怎么吃饭？

**郭先生**：宿舍是三间大平房，接近四十个人。每天提前一天订饭，统计要几个馒头、要一份还是两份菜，第二天领班同学用桶和筐去食堂打回来，再按名单分给大家。

**AI**：周末回家有没有哪次特别难忘？

**郭先生**：我们周末步行回家，要过一条宽宽的大河，叫沭河。有一次夏天水很大，桥上都是洪水，我们三四个同学找了平坦的地方，东西放在肩上，拉着手过河，水能没到半腰。现在想想还是比较危险。

### 3. 大学：医院里的军装

**AI**：大学期间有没有一次生病或意外，让你记住了同学？

**郭先生**：大二得了十二指肠球部溃疡，住进当地部队医院，不到两周。同学结队来看我，还把老师讲的内容带来。我和住院的两位年轻解放军聊大学生活和军队生活，他们后来送了我一套军装。那个年代穿上绿军装是非常荣幸的事。

### 4. 大学毕业：从实习到选择天津院

**AI**：毕业前的实习和毕业设计，对你后来选择工作有什么影响？

**郭先生**：参观和实习让我把书本知识和生产实际联系起来。冀东水泥厂给我的印象特别深，第一次看到窑外分解技术和课本上没有的新装备。毕业设计做的是旋风预热器窑烧成窑尾工艺设计，成绩是优秀。毕业分配按成绩和表现排顺序，我作为优秀毕业生有优先选择单位的机会，选择了自己向往的天津水泥工业设计研究院。

### 5. 入职：邯郸半年实习

**AI**：1987年进入天津水泥工业设计研究院后，最先做的是什么？

**郭先生**：先是见习技术员，和同期来自全国高校、不同专业的28名毕业生一起到河北邯郸水泥厂实习半年。按车间轮转，从矿山开采、原料破碎、生料制备、熟料煅烧，到水泥磨制和包装出厂，全程跟班学习。

**AI**：那段时间除了学习，还有什么生活画面？

**郭先生**：28个人一起住在水泥厂子弟学校，每天一起去食堂吃饭。休息日去周边城镇逛逛，厂里还组织和工厂篮球队、学校篮球队打友谊赛，我担任前锋。日子简单，但很快乐。

## 十一、交付建议

本稿可以直接作为：

- 原型首页的人生阶段和故事卡片内容；
- P05A/P05B 的阶段概要、Story State 和建议追问；
- P06 的场景确认卡片；
- P07 的连续语音演示脚本；
- P09/P10 的整理建议、证据引用和确认交互；
- 后续把 `prototype/app.js` 中骑车去北京等占位内容替换掉的内容依据。

实现时建议把每个对话包单独作为“示例 Session”，同时保存：

- `scope_type`：`life_stage` 或 `story`
- `scope_id`：对应人生阶段或具体故事
- `source_session`：原始会话文件和日期
- `transcript_segment`：来源原话
- `claim_status`：`待确认` / `已确认` / `已忽略`
- `derived_text`：AI 整理出的标题、摘要和追问

这样原型展示的内容会有真实来处，也能把微信旧记录中的编码噪声隔离在原始资料层，不会污染正式人生档案。
