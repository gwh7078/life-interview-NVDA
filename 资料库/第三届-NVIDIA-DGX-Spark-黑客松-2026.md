# 第三届 NVIDIA DGX Spark 黑客松（2026）

## 1. 已确认的活动信息

第三届公开名称为 **NVIDIA DGX Spark 黑客松 · Agent Skills 开发挑战赛**。活动围绕 Agent Skills：把领域知识、工具调用和标准工作流封装成可复用能力，让 Agent 从“会回答”走向“能完成”。活动使用 DGX Spark 的本地计算能力，重点面向 Agent 应用开发和本地多模态实践。

合作/组织信息：NVIDIA Developer Community、StepFun、XSUPERZONE、ASUS（公开活动信息中列出）。

## 3. 规则与参赛边界

- 每队 2—5 人；适合跨专业、跨单位协作。
- 公开信息显示总名额约 100 个；线上训练营不等于正式参赛名额。
- 作品要体现 Agent Skills 的实际价值，不宜只做一个普通聊天机器人或静态网页。
- 第三届的完整评分权重、提交文件格式、代码仓库要求、知识产权条款、云端 API 政策、决赛设备与网络条件，当前仍应以官方后续通知为准。

## 4. 公开训练内容

公开活动介绍提到的方向包括：

1. StepFun 多模态模型 × NVIDIA Agent Skills / Agent Harness；
2. NVIDIA Agent Skills 的设计与实战；
3. 在 DGX Spark 上构建本地视觉 Agent Skills。

这意味着参赛方案最好能展示：结构化输入、技能选择、工具调用、任务执行、结果校验，而不是仅仅展示模型输出一段文字。

## 5. “Agent Skills”对本项目的具体解释

对于“人生采访局”，可把一套技能定义为“可重复执行的采访工作方法”：

| Skill | 输入 | 执行动作 | 输出 |
|---|---|---|---|
| 采访策划 Skill | 人物背景、时间、主题 | 生成采访目标、问题树、敏感问题提示 | 本次采访计划 |
| 动态追问 Skill | 当前回答、情绪/时间线线索 | 判断追问价值，调整问题顺序 | 下一问及追问理由 |
| 人生档案 Skill | 录音/文字/图片/时间线 | 抽取事件、人物、地点、关系与待确认事实 | 结构化人生档案 |
| 故事成稿 Skill | 已确认档案、受访者偏好 | 生成时间线、人物小传、纪念文章或音频脚本 | 可审核的故事初稿 |

## 6. 推荐的项目展示闭环

“输入一段真实访谈素材 → 本地模型整理人物与事件 → Agent 识别空白并追问 → 受访者确认敏感内容 → 形成结构化人生档案 → 生成一份可读故事 → 现场修改并再次生成”。

现场演示至少要让评委看到：

- Skill 如何被发现和调用；
- Agent 如何使用工具而不只是聊天；
- 本地 DGX Spark 在隐私、延迟或多模态处理上的具体优势；
- 哪些内容经过用户确认，避免把模型猜测当作事实；
- 失败时如何降级、重试和人工接管。

## 7. 尚待官方确认的事项

- Agent Skills 的正式目录结构、规范或推荐框架；
- 是否必须使用指定模型、指定 Agent Harness 或指定工具链；
- 是否允许云端模型/API，哪些能力必须在 DGX Spark 本地运行；
- 远程 DGX Spark 资源的申请、配额和截止时间；
- 代码、视频、演示地址、技术报告的提交格式；
- 作品 IP、数据授权和公开展示要求；
- 决赛现场的机器、网络、时间限制与备份方案；
- 奖项、评分权重和最终评委名单。
