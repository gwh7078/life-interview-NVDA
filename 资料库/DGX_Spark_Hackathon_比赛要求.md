# DGX Spark Hackathon 比赛要求

## 一、评审标准

### 1. 项目实用性、行业落地价值与技术创新性（25%）
技术实现、架构与方案具备创新性，充分体现 DGX Spark 平台优势，突破传统思路并解决技术痛点。

### 2. 智能体与模型优化技术深度（25%）
多智能体协同、模型调优深度、Skills 设计与融合、差异化技术方案。

### 3. 项目完整性（20%）
功能完整、运行稳定、前后端完整、文档规范详实、实现逻辑清晰，可以顺利完成演示。

### 4. 平台适配性（15%）
充分发挥 DGX Spark 平台的全栈能力，合理运用 NVIDIA 技术栈、开源模型和 SDK 等工具，以及 StepFun 阶跃星辰模型的使用。

### 5. 演示效果（10%）
Demo 视频演示流畅、展示清晰、逻辑严谨，直观呈现作品价值。

### 6. 赛事征文（5%）
参赛成果记录、DGX Spark 黑客松“一日谈”开发历程。

---

## 二、技术交流规范

为营造纯净友好的技术交流环境，请大家共同遵守：

- 交流群仅交流技术、赛事相关内容，文明交流。
- 欢迎问题反馈组委会，社媒不当言论依规处理追责。
- 社媒分享 AI 作品按平台规范标注 AI 生成。
- 请勿泄露 API 账号、密钥等敏感信息，保障账号安全。

---

## 三、项目提交要求

### 1. 项目开源提交
将完整项目上传至 GitHub、码云等开源平台，以 URL 链接的形式提交至组委会提供的表单。

项目仓库需要包含以下内容：

#### 项目说明文档
撰写 **500 字以上**，说明以下内容：

- 作品特点
- 核心亮点
- 技术实现方案
- 架构设计思路
- 相关优化方案

#### 部署说明
明确说明：

- 项目如何利用本地算力部署智能体
- 如何优化大模型
- 如何设计 Agent Skills

#### 技术栈说明
列明项目使用的：

- NVIDIA SDK
- NVIDIA 相关技术
- StepFun 阶跃星辰相关模型

> 以上内容可在 GitHub 项目中通过 README 的形式体现，并包含 Skill Markdown 文件。

---

### 2. 作品演示视频
提交一段介绍作品的视频，要求：

- 清晰展示作品功能
- 展示核心亮点
- 上传至 B 站
- 将视频 URL 链接提交至表单

---

### 3. 黑客松“一日谈”征文
鼓励在以下技术类社交媒体记录开发过程：

- CSDN
- 知乎
- 其他技术类社交媒体

并将文章 URL 链接提交至表单。

---

### 4. 团队资料
提交团队合影，并上传至表单。
