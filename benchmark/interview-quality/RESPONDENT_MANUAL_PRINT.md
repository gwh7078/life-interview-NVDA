# Interview Quality Benchmark｜人工受访者打印速查版

> **统一规则**
>
> - 只说卡片里的事实，不编。
> - AI 问什么答什么，默认 1–3 句话。
> - AI 不问，不主动透露。
> - 问错前提要纠正。
> - 不知道：答“这个具体我记不太清了 / 说不准”。
> - 不提示 AI 查 Memory / Retriever / Era。
> - A/B/C 三次都按同一规则回答。

---

# Q01｜高考前夜发烧

**开场**
> 1983年那次高考我印象特别深，因为考试前我突然发烧了。

**你知道**
- 1983；正式高考 **7月15日**
- 前一晚发烧；**王明晨老师**送医院输液
- 第二天仍参加考试
- 总分 **486**；本科线 **450**
- 化学 **99.5**；语文 **58**
- 化学课代表，偏爱数理化
- 老师建议报化学相关专业
- 山东建筑材料工业学院｜硅酸盐专业
- 收通知书后才知道和水泥制造有关

**特殊回答**
- 第一次被问日期：<br>
  > 好像是七月初吧，具体哪一天我一下想不起来。
- AI 若核对“7月15日”：<br>
  > 对，是7月15日。你这么一说我就想起来了。
- AI 不核对：不要主动纠正。

**观察**
Memory / 冲突核对 / 重复提问 / 是否继续深挖。

# Q02｜落榜与杨立苗老师

**开场**
> 我高中其实读了五年，中间有一次升学没考上，后来一个老师帮了我很大的忙。

**你知道**
- 1978–1980：店子集公社中学，两年高中
- 喜欢化学，做过化学课代表
- 高中毕业后那次升学 **落榜**
- 初中班主任：**杨立苗**
- 杨老师推荐去参加莒县一中招生考试
- 最后考入莒县一中
- 1980–1983 在莒县一中
- 当时很多农村孩子默认毕业回乡务农
- 父亲甚至已在农村给他盖房

**必须纠错**
AI 若说“第一次没考上高中”：
> 不是没考上高中，我已经读完两年高中了，是高中毕业后的那次升学考试落榜。

**观察**
时间线 / 因果链 / 关键人物 / 命运转折。

# Q03｜趟沭河回家

**开场**
> 莒县一中住校的时候，我周末都是自己走路回家，路上还要过沭河。

**你知道**
- 1980–1983 莒县一中住校
- 周末步行回家
- 路上过沭河，有小水泥桥
- 夏季汛期河水会漫桥
- 一次和同学结伴，水 **没过腰**
- 相互搀扶、手拉手
- **行李举过头顶**
- 现在想起来仍觉得惊险
- 母亲做咸菜疙瘩肉丝，装小瓷罐带回学校
- 也会分给同学

**不知道**
人数 / 天气 / 河宽 / 水流速度 / 是否有人摔倒

**观察**
是否抓住“齐腰深、手拉手、行李举头顶”继续深挖。

# Q04｜从嫌弃“水泥专业”到认同

**开场**
> 刚进大学的时候，其实我并不喜欢自己这个专业。

**你知道**
- 1983 入山东建筑材料工业学院，博山校区
- 硅酸盐专业
- 开始：迷茫、失落，觉得“水泥灰扑扑”
- 入学不久去工厂参观
- 看到窑炉、设备、真实生产流程
- 意识到行业很复杂、建设离不开水泥
- 后来靠老师报告、课堂、讨论、专业展览逐渐理解
- 配料 / 烧成 / 粉磨都有专业知识
- 最后：不再抵触，认定要把这一行学好

**不能编**
第一次新生参观的具体工厂名称。

若 AI 猜厂名：
> 第一次新生参观具体是哪一家厂，我现在不能确定。

**观察**
是否抓住“态度变化”与变化过程，而不是只问课程。

# Q05｜住院与绿军装

**开场**
> 大二的时候我住过一次院，那次还认识了两个让我一直记得的人。

**你知道**
- 大二
- **十二指肠球部溃疡**
- 当地部队医院
- 住院不到两周
- 同学轮流探望
- 认识两位年轻解放军战士
- 两人也住院，病房离得不远
- 聊部队、家庭，慢慢熟悉
- 临走时送了一套 **绿军装**
- 当时军装很稀罕

**不知道**
两人姓名 / 番号 / 籍贯 / 具体疾病 / 后来是否联系 / 军装保存多久

**观察**
是否从“病情”转向真正有价值的“两名战士 + 绿军装”。

# Q06｜冀东水泥厂与第一次去天津

**开场**
> 大学毕业实习那一次，对我后来怎么看这个专业影响挺大的。

**你知道**
- 早些时候去过博山水泥厂、淄博水泥厂
- 毕业实习：
  - 山东水泥试验厂 **1周**
  - 冀东水泥厂 **2周**
- 山东水泥试验厂：立筒预热器窑、旋风预热器窑
- 冀东：先进生产线、机器轰鸣，很受震动
- 冀东总工讲项目引进→筹建→建设→投产
- 现场把书本设备与真实设备对上号
- 更清楚专业用途，也看到行业技术差距
- 从冀东回来后专业信心更强
- 实习后第一次去天津
- 看高中同学 **郭同进**
- 第一次去南开大学、天津大学
- 校园学习氛围让他很受触动

**Era 规则**
AI 可谈历史背景，但别替它确认未知精确日期。
被问具体哪天：
> 我记得是毕业实习期间去的，具体哪一天我记不清了。

**观察**
Memory + Era 是否自然转成追问，而不是给你讲历史课。
